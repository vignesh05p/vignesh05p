## About me

I'm Vignesh Prabhu, an AI engineer working on LLM systems that run in production, not just in notebooks.

At Manipal Dot Net I:

- Fine-tuned and productionized a domain-specific **Qwen LLM** for automated medical and instructor assessment.
- Replaced an **AWS Bedrock** grading pipeline with a **self-hosted LLM** on on-demand GPUs, cutting comparable inference cost by about **90%**.
- Built a hybrid setup: the self-hosted model does core grading, Claude via Bedrock writes feedback, with automatic fallback to Bedrock if the self-hosted model fails.
- Serve models behind **OpenAI-compatible APIs** (llama.cpp, vLLM).
- Profile LLM inference on **NVIDIA L40S** GPUs with Nsight and CUPTI, comparing Marlin vs Triton INT4 MoE kernels.
